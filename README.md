# shop-checkout-demo

A tiny checkout service used as the demo repository for **Doneproof**, a Jira app that lets work move to Done only when its acceptance criteria are proven by real evidence: merged pull requests, green CI, and a verdict on each criterion.

The Jira work item `SHOP-1` ("Checkout fails for EU cards that require 3-D Secure") links to the pull request in this repository that fixes it.
